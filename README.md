# 🔬 Python VLSI Circuit Analyzer

A Python-based VLSI and digital circuit analysis project that models fundamental digital circuits and introduces basic CMOS power and timing analysis.

The project progresses from logic gates and Boolean algebra to sequential circuits, CMOS logic, power analysis, delay analysis, and a final VLSI circuit analyzer.

---

## 🚀 Features

- Logic gate analysis
- Boolean algebra operations
- Karnaugh map solver
- Combinational circuit analysis
- Half adder and full adder
- Half subtractor and full subtractor
- Ripple carry adder
- Ripple borrow subtractor
- Multiplexer
- Demultiplexer
- Encoder
- Decoder
- Priority encoder
- Sequential circuit analysis
- SR, D, JK and T flip-flops
- Up and down counters
- Ring counter
- Johnson counter
- Shift registers
- CMOS inverter
- CMOS NAND
- CMOS NOR
- Dynamic power analysis
- Static/leakage power analysis
- RC propagation delay analysis
- Final integrated VLSI analyzer
